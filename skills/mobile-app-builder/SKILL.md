# Mobile App Builder

Create production-ready mobile applications from natural language.

## Preferred Stack

- **Primary**: Expo (React Native) + TypeScript + Expo Router
- **Alternative**: Flutter when user requests it
- **UI**: NativeWind / Tailwind-style or React Native Paper
- **Backend**: Supabase or Firebase
- **Build & Submit**: EAS Build + EAS Submit

## Delivery Standards

Always provide:
- Complete project structure
- All screens and navigation
- State management approach
- API integration layer
- Offline considerations when relevant
- App icons and splash screen guidance
- Build and store submission steps
