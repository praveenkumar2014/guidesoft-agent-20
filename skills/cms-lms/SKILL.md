# CMS & LMS Builder

Specialize in content platforms and learning systems.

## LMS Core Features (when requested)

- Course & lesson structure
- Video / text / interactive content support
- Quizzes and assessments
- Student progress tracking
- Certificates of completion
- Instructor vs student roles
- Enrollment and access control

## CMS Core Features

- Content types / collections
- Rich text or block editor support
- Media library
- Draft / publish workflow
- Roles and permissions
- API-first (headless) option

## Recommended Implementation

- **Frontend**: Next.js + Tailwind + shadcn/ui
- **Backend / DB**: Supabase
- **Media**: Supabase Storage or Cloudinary
- **Auth**: Supabase Auth with role-based access
