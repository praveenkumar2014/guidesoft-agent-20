# Tech Stack Decision Log (GUIDESOFT AGENT defaults)

These are the recommended defaults. Override only when the user explicitly requests something else.

## Web Full-Stack
- Framework: Next.js 15 (App Router) + TypeScript
- Styling: Tailwind CSS + shadcn/ui
- Database / Auth / Storage: Supabase
- Payments: Stripe
- Deploy: Vercel

## Mobile
- Expo + React Native + TypeScript + Expo Router
- UI: NativeWind or React Native Paper
- Backend: Supabase
- Builds: EAS

## Why these choices
- Excellent AI code generation quality
- Free tier friendly
- Fast iteration
- Production proven
- Strong TypeScript support
- Easy one-click deploys
